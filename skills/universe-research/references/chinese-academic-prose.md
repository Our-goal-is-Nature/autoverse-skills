# 中文学术综述：行文与描述

Agent 撰写综述或研究脉络正文时阅读本文件。检索、核验、命令以主技能与 `autoverse-cli/references/commands.md` 为准。

本文件只写与现技能不冲突的行文条款。不写：引言必须交代「目的与必要性」；按被引次数或期刊影响因子选篇。

## 全文逻辑

正文按主题组织，不按单篇罗列。每一节只比较同一主题下已核验篇目的方法、结果或限度。一致与分歧写入讨论，不作为各节小标题。

结论或结语提炼全文可以成立的判断，不重复各节摘要。推不出结论时，只写讨论中已写出的限度与未决问题。

读者读完后应能看出：本题比较了哪些对象、各研究在何处一致、何处分歧、何处证据不足。不要用「综而不述」：只列题名与年份、不比较内容。不要用「述而不引」：论断后面没有对应编号。

引用须忠于已核验篇目的摘要所能支持的内容。Agent 的判断与文献原文要能分开读。无摘要的篇目可以进入一次 `batch` 并列入证据表，不得根据该篇写结论。

## 各节写什么

**引言**：只陈述用户题目里的对象，以及本文比较的范围。不先定义整个学科。不写「本文回答什么」。出发对象为论文或作者时，写出那一篇或那一位。

**文献来源**：写出检索途径、时限、别名如何纳入、纳入篇数、判断依据摘要。系统性综述常见的「用了哪些数据库、哪些检索词、哪段时间」可以写在这里。不写命令名，不写核验过程。

**主题各节**：按学科 reference 中的主题组织。小标题对应比较对象，不对应单篇论文。节内做归纳与对照，不按检索顺序堆段落。

**讨论**：集中写一致、分歧、证据不足。文字不夸大。不能完全肯定的内容留有余地。

**结语**：概括讨论中已成立的判断。不是各节的再述。

**参考文献**：顺序编码，与正文首次出现和证据表行号一致。著录见主技能。

## 描述怎么写

一句写清：哪项研究、在什么对象或条件下、得到什么结果或限度。不要用空主语（「研究表明」「有学者指出」）代替篇目编号。

同一科学技术名词全文只用一种规范名称。少用未经审定的字母词；必须使用时，首次按术语文件括注。不用「俗称」「曾称」。

先见文字，后见图或表。图、表有编号与题目。

量和单位、数字用法遵循 GB/T 7713.2—2022 的编排条款：计量用阿拉伯数字；单位与数值之间留空；单位英文缩写（如 rpm）不当作单位符号。综述很少需要公式时，可以不写公式。
